# 雾津日报 · 报老板不好当

《报老板不好当》是一款中文叙事经营游戏。你接手创刊 112 年的《雾津日报》，在截稿前决定什么上头版、派谁去采访，以及怎样回应广告主、董事会与信源的压力。

[在线试玩](https://wujin.bylia.cn/)

## 怎么玩

游戏共三期，从港口航道受阻，到本报印刷厂停工，再到第三码头的二十七名病人。每期从选题、框架、标题和记者委派开始，随后可能收到来电或新线索。你的选择会改变报社资金，以及公信力、独立度、人文关怀、商业成功和影响力。资金耗尽会提前停印。结局会生成一份属于这局的报纸。

手机端建议横屏。当前版本暂不支持关闭页面后继续游戏。

## 本地运行

在仓库根目录运行以下命令，然后打开 [本地游戏](http://localhost:8000/)。

```sh
python3 -m http.server 8000
```

游戏使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖，也无需后端或数据库。

离线打包需要 Python 的 Pillow 库。在虚拟环境中安装依赖并运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Pillow
python tools/build_offline.py
```

脚本会在项目根目录生成 `雾津日报.html`。可直接用浏览器打开，也可以将它作为 `index.html` 部署到静态网站服务器。

## 项目结构

- `index.html`：游戏入口。
- `src/`：剧情、选项、分数与结算规则。
- `proto/`：游戏界面、结算报纸及相关素材。
- `game_assets/`：入口页面使用的图片素材。
- `tools/build_offline.py`：离线单文件打包脚本。
